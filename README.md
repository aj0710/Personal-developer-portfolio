## ✨ Key Features

- **🎨 Ambient Glassmorphism & Modern UI**: Built with custom HSL and hex design tokens, subtle ambient orb glow, noise texture backdrop, and smooth micro-interactions.
- **🌓 Dual Dark/Light Theme**: Persistent theme switching using `localStorage` and `data-theme` attribute with smooth transitions.
- **💻 Interactive Developer Terminal**: Bento-style terminal card with dynamic JSON telemetry and typewriter heading.
- **🔍 Filterable Technical Skills**: Filter competencies across **Core Languages**, **Frontend**, and **Backend & Database** with animated progress indicators.
- **📂 Live GitHub Projects Grid & Architecture Modal**:
  - Showcases real-world open-source repositories from [github.com/aj0710](https://github.com/aj0710).
  - Detailed case study modal outlining system architecture decisions, problem solved, feature highlights, and direct live demo / repository links.
- **🎓 Academic & Journey Timeline**: Visual milestone timeline highlighting MCA studies at NIIS College and full-stack software development experience.
- **📬 Interactive Contact Hub**:
  - Validated contact form with interactive submit handler.
  - Direct email copy-to-clipboard button with instant toast feedback.
- **📱 100% Mobile Responsive**: Dedicated mobile slide-out drawer navigation, touch-friendly tap targets, and responsive CSS grid/flexbox layouts.
- **⚡ Zero Bloat & Instant Loading**: Pure semantic HTML, vanilla CSS, and modular ES6 JavaScript with zero heavy runtime framework overhead.

## 💻 Getting Started Locally

### Prerequisites
You only need a modern web browser (Google Chrome, Firefox, Microsoft Edge, or Safari).

### 1. Clone the Repository
```bash
git clone https://github.com/aj0710/test.git
cd test
```

### 2. Run Locally
Because this project uses vanilla web standards, you can run it in multiple ways:

#### Option A: Direct Browser Opening
Simply double-click `index.html` or open it with your browser:
```bash
start index.html
```

#### Option B: VS Code Live Server (Recommended)
1. Open the project folder in **VS Code**.
2. Install the **Live Server** extension (`ritwickdey.LiveServer`).
3. Right-click `index.html` and click **"Open with Live Server"**.

#### Option C: Node.js / npx serve
```bash
npx -y serve .
```

## 🚢 Deployment

### GitHub Pages (via GitHub Actions)
The repository comes pre-configured with `.github/workflows/deploy.yml`. Whenever changes are pushed to the `main` branch, GitHub Actions builds and deploys the site automatically.

To enable GitHub Pages in your repository:
1. Navigate to **Settings > Pages** in your GitHub repository.
2. Under **Build and deployment > Source**, select **GitHub Actions**.
3. Push to `main` or trigger the workflow manually under **Actions**.

### Vercel Deployment
The repository includes a production-ready `vercel.json` configuration file with:
- `cleanUrls: true` for clean path routing.
- Security response headers (`X-Content-Type-Options`, `X-Frame-Options`, `X-XSS-Protection`).
- Long-term immutable caching for static assets in `/assets/`.

To deploy on Vercel:
```bash
npm i -g vercel
vercel
```
Or import the repository directly via the [Vercel Dashboard](https://vercel.com/new).

## ⚙️ Customization Guide

### 1. Updating Projects
Edit `js/projects-data.js` to modify titles, descriptions, categories, architecture specs, or repository links:
```javascript
const projectsData = [
  {
    id: "your-project-id",
    title: "Your Project Name",
    category: "fullstack", // "fullstack" | "backend" | "ai"
    badge: "Tech Stack",
    summary: "Brief project summary...",
    image: "assets/images/project1.jpg",
    tags: ["React", "Node.js"],
    demoUrl: "https://...",
    githubUrl: "https://..."
  }
];
```

### 2. Customizing Theme Colors & Styles
All design tokens are defined at the top of `css/style.css`:
```css
:root {
  --bg-base: #0a0d14;
  --accent-primary: #6366f1;   /* Primary Brand Accent */
  --accent-secondary: #06b6d4; /* Secondary Cyan Accent */
  --accent-emerald: #10b981;   /* Status Green */
}
```

### 3. Updating Personal Contact & Metadata
Update meta tags, email, and social profiles directly inside `index.html`.
